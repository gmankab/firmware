## Verified input and architecture

- Input: `usr/lib/firmware/qcom/sm8150/Xiaomi/nabu/adsp.mbn` from recovered,
  intact `firmware-xiaomi-nabu-1-r2.apk`. Source package is private input, not
  tracked by Git.
- Exact reference SHA-256:
  `4b579e5dc1333d634e5bdc93f3314e357e0e30dab7140833f6cc7aef086b1c1e`.
- ELF32 little-endian, `e_machine = 164` (Qualcomm DSP6/Hexagon),
  `e_flags = 0x66` (v66), ELF entry/physical entry = `0x8be00000`.
- First `R E` PT_LOAD: file `[0x3000, 0x521c)`, `p_filesz = 0x221c`,
  `p_memsz = 0x3000`, ELF vaddr = `0xf0000000`, physical addr =
  `0x8be00000`. File offset is **not equal** to CPU vaddr/paddr.
- The entry fragment `[0x3000, 0x3024)` comprises precisely nine A32-sized
  *Hexagon* (not ARM32) packets/instructions: initial jump, six vector
  self-loop traps, distant jump to RX-relative `0x1158`, and initial `r0=0`.
  Generated from `tools/adsp-boot-vectors.S`, no binary `.word`/`.incbin`.
  This is **36 independently generated bytes**; SHA-256:
  `e945606214436af167625a339bfa36f4df34c5860f1507649d29b755d608550b`.
- The generator compiles source with LLVM6 Hexagon `-mcpu=hexagonv65` **only
  for instructions proven common to v65/v66**. It refuses relocations and
  invalid ELF section layouts. For other executable v66 instructions,
  do not assume the v65 assembler is a complete or correct toolchain.

## Checkpoint 02: independent timer and controller fragment

A second, **disjoint** fragment has now been independently source-assembled
at file offsets `[0x4218,0x4488)` (`0x270 = 624 bytes`), executable PT_LOAD
relative `[0x1218,0x1488)`, physical addresses
`[0x8be01218,0x8be01488)`. The initial 112 bytes formed checkpoint 02;
checkpoint 03 adds the adjacent 512 bytes of actual hardware-register
initialization (three paths, each with nine named configuration writes). This covers a three-instruction register-save
packet, global-timer polling/conditional retry, restoration and a return,
followed by controller status comparison against `0x100`/`0x200` and
three conditional branch destinations. The code uses source labels, combined
predicate/branch packet syntax, `immext` generated from constants and no
binary code words. The full 624-byte region SHA-256 is
`632f108b4b85b96d6641d56f0bb1581633a25cbefb06d0f616d406b2e4eac0c1`.

**Cumulative independently rebuilt executable bytes: 660** (`36 + 624`).
They are **not contiguous**; there is a gap after the first entry fragment.
The first missing executable byte remains at file `0x3024`; the missing
interval `[0x3024,0x4218)` must not be hidden or counted as rebuilt.

## Reproduction

```sh
HEXAGON_LLVM_MC=/path/to/llvm-mc
NABU_ADSP_REFERENCE=/private/firmware/adsp.mbn
python3 -S tools/emit-adsp-entry.py \
  --llvm-mc "$HEXAGON_LLVM_MC" \
  --output /tmp/adsp-boot-36.bin \
  --reference "$NABU_ADSP_REFERENCE"
python3 -S tools/emit-adsp-entry.py \
  --segment counter-controller \
  --llvm-mc "$HEXAGON_LLVM_MC" \
  --output /tmp/adsp-controller-624.bin \
  --reference "$NABU_ADSP_REFERENCE"
HEXAGON_LLVM_MC="$HEXAGON_LLVM_MC" \
NABU_ADSP_REFERENCE="$NABU_ADSP_REFERENCE" \
python3 -S -m unittest discover -s tests -p 'test_*.py'
```

### Tests

- Newly added: strict ELF32 Hexagon/REL parser checks, size/alignment, six
  vector self-loops, deterministic compilation, relocations rejection,
  full-reference SHA validation, exact file-offset bytes comparison and
  negative mismatch test.
- Original ADSP sample generated by LLVM 6 and compared against entire
  reference SHA and first 36 bytes: zero byte differences.
- Baseline Python regression suite: 22 tests, 3 pre-existing skips,
  when the `HEXAGON_LLVM_MC` and `NABU_ADSP_REFERENCE` environment variables
  are present.
- Rust workspace tests and release build are **not executed**: rustc and
  `cargo` were unavailable (the large downloads zstd archive is corrupted
  later, although the ADSP input APK was successfully recovered).

## Remaining work

**First not independently rebuilt executable file byte:** `0x3024`
(relative to executable PT_LOAD `0x24`, physical address `0x8be00024`).
The remainder of the executable PT_LOAD and all other program segments,
including BSS and hashes/signatures, remain unreconstructed. The generated
36-byte fragment is **not** a complete, authenticated, or flashable firmware.
Hexagon v66 instruction support and packet scheduling will be needed to
reconstruct subsequent SYSCFG/DCACHE/ICACHE bootstrap instructions.

These changes are confined to:
`tools/adsp-boot-vectors.S`, `tools/adsp-counter-controller.S`,
`tools/emit-adsp-entry.py`, `tests/test_adsp_bootstrap.py`,
and this progress document.
